# Operator Guide

## First Deployment
1. Register operator, locations, hygiene certifications, staff and robots.
2. Import existing service and incident-reporting history.
3. Run read-only hygiene-certification-scope and food-prep/delivery robot
   mission dry-runs.
4. Configure safety-class allowed sets and human sign-off paths.
5. Publish a dry-run incident report and audit export.

## Minimum Production Controls
- hygiene-certification-scope validation before any dispatch
- governor gate on every robot action before dispatch
- human sign-off for :high/:safety-critical actions (allergen handling,
  food-temperature control, cross-contamination risk)
- evidence-backed incident reports
- audit export for every dispatch, sign-off and report
- backup manual service process

## Certification
Certified operators must prove robot-safety integrity, hygiene-
certification discipline, evidence-backed incident reporting and human
review for safety-affecting actions.
